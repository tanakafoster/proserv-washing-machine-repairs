# Citations (NAP) and directories

Search engines compare your business details across the web. Use the block below **exactly the same way everywhere**: same spelling, same phone format, same website URL. Small differences ("Pro Serv", "ProServ Repairs", a different number) weaken local rankings.

## The exact block to copy

```
Business name:  ProServ Washing Machine Repairs
Phone:          079 895 0496
Website:        https://proservwashingmachinerepairs.co.za/
Email:          info@proservwashingmachinerepairs.co.za
Address:        Service-area business, no public address. Area: Gauteng
Hours:          Your real hours, the same everywhere (add them to src/data/site.ts too)
Category:       Washing machine repair / Appliance repair
Areas served:   Johannesburg, Pretoria, Centurion, Sandton, Midrand, East Rand
```

Where a directory asks for an international number, use **+27 79 895 0496**.

## Tips
- Use the same logo and description everywhere.
- Link to the home page (or the contact page if the directory has a "book" field).
- Keep a simple spreadsheet of where you've listed, with logins, so you can update all of them if your hours or number ever change.
- Don't buy bulk "citation packages" that submit to hundreds of low-quality sites.
