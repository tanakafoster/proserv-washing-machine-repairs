# SEO keyword map

Every indexable page targets **one** primary keyword and 2–4 secondary keywords. No two pages share a primary keyword. Phrasing follows how South Africans search (e.g. "washing machine repairs" plural, "won't turn on", "top loader", Rand pricing).

"Near me" is deliberately **not** used in copy. Local-pack and "near me" rankings come from the Google Business Profile (see `GBP-SETUP.md`), reviews and consistent NAP citations (`CITATIONS.md`), not from repeating the phrase on the page.

Rules used when writing each page:

- Title under 60 characters: primary keyword first, then `| ProServ`.
- Meta description under 155 characters: keyword, a reason to call, and 079 895 0496.
- One H1 containing the primary keyword, and the keyword within the first 100 words.
- Secondary keywords used naturally in H2s and body copy, never stuffed.

## Cannibalisation checks

- `washing machine error codes` (hub) vs `washing machine showing error code` (problem page): the hub is a brand directory of code guides; the problem page explains what to do when any code appears and routes to the guides.
- `washing machine repair cost` (cost page) owns "bearing replacement cost" as a secondary; the bearings blog post links to it rather than competing with prices.
- `washing machine noisy when spinning` (problem page) vs `worn washing machine bearings` (blog): the problem page covers all causes of noise; the blog post goes deep on bearings only and links back.
- `front loader repairs` (service) vs `front loader vs top loader` (blog): commercial vs informational intent.
